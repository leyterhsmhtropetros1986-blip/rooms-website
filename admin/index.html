Τεκμηρίωση Backend

Αυτό το dashboard είναι UI prototype. Ακολουθεί η λίστα backend tasks που απαιτούνται για πλήρη λειτουργία:

  • Secure authentication (JWT / session)
  • PostgreSQL ή MongoDB database
  • REST API: reservations, guests, reviews, offers
  • File upload service (room photos)
  • Email notification service (SendGrid / SMTP)
  • AI API integration (OPENAI_API_KEY)
  • Meta Graph API (META_ACCESS_TOKEN)
  • iCal feed για Booking.com / Airbnb sync
  • GDPR-compliant data handling
